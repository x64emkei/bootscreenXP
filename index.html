BootScreenXP

Boot Screen Utility for Windows XP

Welcome to the legacy BootScreenXP help and information site. BootScreenXP is a small utility for working with custom Windows XP boot screens.

Before you begin
BootScreenXP is intended for Windows XP-era systems. Always keep a backup of important system files before changing boot resources.

What can I do here?

  • How To — basic steps for preparing and applying a boot screen.
  • Help — troubleshooting and common questions.
  • About — project information and credits.

Legacy first
