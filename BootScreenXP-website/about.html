About BootScreenXP

Classic Windows XP boot-screen utility

BootScreenXP is presented here as a legacy Windows XP utility project, with a web interface styled after the supplied BootScreenXP splash artwork.

Project identity

Design notes

The site uses the supplied splash.bmp as its header artwork. The blue background, orange divider, rounded-looking navigation treatment and Windows XP-era typography are carried through the rest of the pages.
