Help & FAQ

Common problems and checks

The boot screen does not appear

Confirm that the change was actually applied, then restart the computer. Also verify that the image format and dimensions are supported by your particular BootScreenXP build.

Windows reports a system-file problem

Stop and restore the original backup if you have one. System-file changes should not be repeated blindly. Use Windows recovery or another known-good copy when appropriate.

The image looks distorted

Check the original image dimensions, color depth and format requirements for your version of the utility. A preview may not always represent the exact startup display.

Can I use this on Windows 7 or later?

BootScreenXP is designed around Windows XP. Do not assume that a Windows XP boot-resource method is compatible with newer versions of Windows.

Internet Explorer looks different

That is expected to some degree. This site intentionally avoids modern CSS and JavaScript features so the basic pages remain usable in IE6, IE7 and IE8.

Still stuck?
Write down your Windows version, BootScreenXP version, the image format you used, and the exact error message. Those details make troubleshooting much easier.
